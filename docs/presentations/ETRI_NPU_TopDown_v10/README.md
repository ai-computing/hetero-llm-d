## 최종 구성

1. 전체 지도: 활용 인프라와 우리가 분석·개발한 계층.
2. NPU에서는 장비뿐 아니라 실행 조건도 관리해야 함.
3. 모델 → 실행 준비 → NPU 실행: 분석 범위와 저수준 IR의 쉬운 설명.
4. 기존 엔진 안에 우리 코드를 연결: 세부 구현 이름·절차 생략.
5. KV 전달로 NPU 사이의 실행을 분리한 작업.
6. lmd-top: 모델·컴파일 산출물, 컴파일·배포 작업, 실행·자원 상태를 관리. 실제 화면 포함.
7. 확보한 기반에서 비용 예측과 자원 배치 정책으로 협업 제안.

## 해석 범위

전체 지도는 단일 통합 자동 제어기의 구축을 의미하지 않는다. lmd-top은 벤더 컴파일 작업을 관리하며 컴파일러 자체가 아니다. 화면은 캡처 당시 운영 상태이고 성능 비교 자료가 아니다. 저수준 실행 연결은 완전한 attention 알고리즘 교체나 성능 개선 검증을 뜻하지 않는다.
