# 편집 가능한 발표자료

9장. 기존 v10 이미지의 구성·색·계층 관계를 참고하여 텍스트, 카드, 화살표, 개념 아이콘을 PowerPoint 기본 객체로 재구성했다. 전체 슬라이드 배경 이미지를 사용하지 않는다. 발표자 노트는 없다.

- 1–5: 환경 → 실행 조건 → 내부 분석 → 커스텀 실행 → NPU PD.
- 6: 모델·산출물 관리 — 새로 캡처한 실제 Library 화면.
- 7: 컴파일·배포 — 이전 실제 캡처의 Activity 부분을 비파괴 크롭하여 확대. 캡처 당시 상태이며 현재 상태를 보장하지 않는다.
- 8: 실행·자원 관측 — 실제 observe 모드 Overview → Infra 화면 녹화 GIF. GIF 바이트가 PPT 내부에 보존됐는지 검사했다. 이 환경에서는 Microsoft PowerPoint의 실제 슬라이드 쇼 재생까지 검증하지 못했다.
- 9: 협업 질문.

텍스트·도형·화살표·개념 아이콘 구성요소는 개별 편집 가능하다. 제조사 사진과 로고는 승인된 이미지에서 잘라 쓴 개별 그림 객체이며 크롭·교체·이동·크기 변경 가능하다. 스크린샷과 GIF 내부의 글자는 편집 가능한 텍스트가 아니다.

글꼴: Noto Sans CJK KR. 글꼴이 없는 PC는 대체 글꼴 때문에 줄바꿈이 달라질 수 있다. PDF는 고정 미리보기이며 GIF가 움직이지 않는다.

빌드: scripts/build-kcloud-editable-v11.py. 캡처: scripts/capture-lmd-sections.py. 캡처는 읽기 전용 observe와 메뉴 이동만 수행하며 외부 컴파일·배포는 실행하지 않았다. 원본 PTY 기록은 assets/*.cast에 보존했다.
