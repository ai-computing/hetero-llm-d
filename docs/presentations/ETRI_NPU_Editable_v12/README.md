## 편집과 재생

텍스트·도형·화살표·개념 아이콘은 개별 편집 가능하다. 사진·로고·GIF는 별도 그림 객체이며 내부 픽셀은 텍스트/도형으로 편집되지 않는다. 그라데이션은 DrawingML 기본 채우기다. 원본 이미지의 질감을 완전히 동일하게 재현한 것은 아니다.

GIF 3개의 원본 바이트가 PPT에 보존됐는지 검사했다. GIF의 중간 프레임(모델 Zoo, 컴파일 폼, 배포 폼)도 확인했다. Microsoft PowerPoint의 실제 슬라이드 쇼는 이 환경에서 실행하지 못했으므로 발표 PC에서 재생 확인이 필요하다. PDF는 정적 첫 프레임만 표시한다. 글꼴은 Noto Sans CJK KR이다.

## 안전한 실제 캡처

scripts/capture-lmd-options.py로 실제 PTY를 녹화했다. 옵션 폼의 UI 권한 요구에 따라 admin 모드로 열었지만 사용한 키는 메뉴 전환, c/d 폼 열기, j/l 선택 이동 및 Esc 취소뿐이다. Enter, apply, 파일 저장, 컴파일·배포 실행은 하지 않았다. 폼에서 바뀐 값은 취소했으며 외부 리소스를 변경하지 않았다. 원본은 assets/options.cast.
