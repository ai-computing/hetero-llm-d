1. lmd-top_source_v0.36.0_20260928.zip
현재 작업 소스 스냅샷. Cargo.toml 버전 0.36.0이며 미커밋 개선을 포함합니다.
본체 소스, 빌드에 필요한 내장 Go 확장·문서·카탈로그, 테스트·빌드 설정을 포함합니다.
외부 의존성은 lock 파일로 관리하며 Cargo 캐시 또는 인터넷 접근이 필요합니다.
빌드 산출물, Git 이력, 로컬 인증 설정은 제외했습니다.
압축 무결성·원본 파일 일치 검증과 추출본 cargo check --locked --offline 통과.
등록 의뢰서의 본체 69개 파일 규모와 전체 패키지 파일 수는 범위가 다릅니다.

3. lmd-top_execution.mp4
실제 프로그램을 조회 전용(--mode observe)으로 실행한 약 54초 영상입니다.
Kubernetes와 Prometheus에서 조회한 실제 상태이며 합성 지표는 사용하지 않았습니다.
노드·파드 장애나 비활성 지표는 촬영 당시 상태 그대로이며 정상 운영을 가정한 데모가 아닙니다.
화면 이동 키만 입력했으며 리소스 생성·삭제, 컴파일, 배포 및 트래픽 생성은 수행하지 않았습니다.
형식: H.264 MP4, 15fps, 무음. PNG와 동일한 터미널 화면을 인코딩했습니다.

4. lmd-top_execution.gif / lmd-top_execution.cast
동일 실행의 GIF 미리보기와 재생 가능한 원본 asciicast(ANSI 출력) 기록입니다.
원본 cast는 asciinema play lmd-top_execution.cast로 재생할 수 있습니다.
